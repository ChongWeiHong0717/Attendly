# V1.1 Changes

## Student identity
- Student ID can be entered manually when adding a student.
- Blank Student ID is auto-generated from the permanent sequence.
- Manual and generated Student IDs remain unique and never reused.
- Optional IC/MyKid field is retained as a secondary identifier.
- Duplicate Student ID and IC/MyKid values are rejected with clear messages.
- Internal database `Student.id` remains separate from the visible Student ID.

## Interface
- Full Campus Signal visual refresh.
- Mobile-first responsive layouts across teacher and admin pages.
- Persistent desktop sidebar and mobile side drawer; no bottom navigation.
- Mobile student/account screens use stacked cards instead of squeezed tables.
- Class roster search is the only student text search and includes a clear button.
- Attendance controls use large touch targets and a reachable mobile save action.
- Forms, dialogs, empty states and error messages use shared styles.

## Safer actions
- Browser confirm dialogs were removed from product workflows.
- Student archive and class removal use app-owned confirmation dialogs and Undo.
- Account disabling uses confirmation and Undo.
- Academic-year rollover keeps its stronger typed confirmation and is not reversible.

## Deferred
- Excel/CSV import is not part of V1.1 and remains future work.
- NFC hardware integration remains future work.
