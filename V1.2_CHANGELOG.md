# V1.2 Changes

V1.2 is a visual and interaction-focused release. V1.1 functionality and data rules are preserved.

## Visual identity

- Upgraded the design system to **Campus Signal 1.2**.
- Richer professional palette: deep navy structure, teal-blue primary actions, cool light surfaces, restrained sky/amber accents, and clearer green/red attendance states.
- Updated card, button, field, table, dialog, navigation and feedback styling.
- Added the finalized shared product-family rules to `DESIGN.md` for reuse by the future NFC desktop application.

## Teacher interface

- Teacher class cards are substantially larger and normally use a two-column desktop layout instead of small three-column tiles.
- Added stronger Form labeling, class identity hierarchy and a dedicated Open class action area.
- Class page now uses a larger class-focus panel with student count, Present/Absent metrics and a more prominent attendance action.
- Student roster rows are larger and easier to scan on phones and laptops.
- Attendance now includes a marked-student progress bar, richer summary blocks and clearer per-student status surfaces.

## Admin interface

- Forms 1–5 class management is reorganized into clearer Form sections with counts and larger class modules.
- Student filtering has a dedicated filter surface and stronger student/table hierarchy.
- Teacher/account management has clearer account status and summary metrics.
- Academic year screen now emphasizes the active year while keeping rollover deliberately high-friction.

## Login and shell

- Desktop login now uses a restrained school-operations identity panel while mobile keeps a compact sign-in layout.
- Sidebar and header styling were strengthened without changing the sidebar navigation model.
- Mobile remains side-drawer navigation only; no bottom navigation was added.

## Unchanged V1.1 rules

- Optional Student ID with auto-generation when blank.
- Optional IC/MyKid and duplicate checks.
- Student search only inside a class.
- Undo for reversible destructive actions.
- Excel/CSV import remains deferred.
- NFC hardware integration remains future work.
