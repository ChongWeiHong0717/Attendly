# Attendly v1.3 — Teacher attendance overview

## Website teacher class view
- Added a date picker directly to each teacher class page.
- The selected date is preserved when opening Take/Edit Attendance and returning to the class page.
- Attendance summary now calculates immediately without requiring the teacher to open Edit Attendance first.
- Before a manual attendance session is saved:
  - Present = students with an NFC check-in for the selected date.
  - Absent summary = students who have not checked in yet (shown as "Not checked in" context).
  - Students remain UNMARKED in the attendance editor until the teacher explicitly confirms Present or Absent.
- After attendance is saved, the class summary displays the saved Present and Absent totals.
- Student roster rows show the selected date's state:
  - Present · NFC
  - Not checked in
  - Present / Absent when saved attendance exists.

## Backend
- Attendance snapshot now returns a provisional absent/not-checked-in count before manual attendance is finalized.
- Existing final attendance behavior remains unchanged.
