# Attendly v1.4 — App NFC Check-In Date Selector

## Desktop app

- Added a Check-In Date selector to the teacher NFC check-in terminal.
- Defaults to the current local day.
- Selected date is sent to the existing `/api/nfc/check-in` endpoint.
- Date selection is locked while continuous scanning is active to prevent mixed-date sessions.
- Changing the date clears the current on-screen scan list and latest scan result.
- Terminal status shows the active check-in date.

## Backend

- Existing NFC check-in API already supports an explicit `YYYY-MM-DD` date.
- Duplicate response wording now says "for this date" instead of "today", so past-date testing is accurate.

## Intended use

This selector is primarily for staging/testing. Normal operation requires no extra action because the app defaults to today.
