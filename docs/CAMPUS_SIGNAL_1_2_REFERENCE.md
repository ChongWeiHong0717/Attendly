# Campus Signal 1.2 — Cross-App Reference

Use this when building the future NFC PC application so it matches the web attendance system.

| Role | Value |
| --- | --- |

## Typography

- Heading: Segoe UI Variable Display / Segoe UI / system sans-serif.
- Body: Segoe UI Variable Text / Segoe UI / system sans-serif.
- Student ID / device values: Cascadia Mono / Consolas / monospace.

## Shape

- Small radius: 8px.
- Normal controls: 14px.
- Main panels: 18px.
- Pills only for statuses and compact metadata.

## NFC desktop app mapping

- Main window/navigation chrome: structural navy.
- Begin Taking Attendance: primary teal-blue.
- Reader connected / successful scan: green.
- Reader warning / pending: amber.
- Failed scan / disconnected error: red.
- Scan feed background: white on cool application background.
- Student/device IDs: monospace.
- Keep copy short and operational.
